# Totebot

Mission:
Identify races worth observing, not predict winners.

Preserve:
- chronological Betfair queue
- observation history
- human-in-the-loop pruning
- one-shot/manual queue behaviour

The agent may:
- analyse race state
- inspect history
- rank races
- improve code
- write recommendations

The agent must not:
- place bets
- alter Betfair credentials
- silently discard historical observations
- change production emitter behaviour without explaining the effect
